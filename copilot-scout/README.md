# Copilot Studio — Scout (Implementation Intake Agent)

**Built by:** Jennifer Ugarte | Ugarte Consulting

## What It Does
Scout is an AI-powered implementation intake agent built in Microsoft 
Copilot Studio. It conducts structured discovery conversations with 
clients, gathers requirements, and applies AI intelligence to generate 
next steps and action items for the implementation team.

## Why I Built It
Implementation requirement gathering is time-consuming and inconsistent. 
Scout standardizes the intake process and reduces the manual effort 
required to translate client responses into actionable project tasks.

## Tech Stack
- Microsoft Copilot Studio
- Power Platform (dev tenant)
- Custom topic branching and HITL escalation design

## Status
Portfolio proof-of-concept. Not a live client deployment.
