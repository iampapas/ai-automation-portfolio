# Copilot Studio — AI Onboarding Assistant

**Built by:** Jennifer Ugarte | Ugarte Consulting

## What It Does
An AI-powered onboarding assistant built in Microsoft Copilot Studio, 
trained on six years of real implementation documentation from Prism PPM 
— including SOPs, playbooks, training guides, and escalation procedures. 
Helps clients get answers to onboarding questions without waiting for 
their implementation specialist.

## Why I Built It
Client questions during onboarding slow down implementations and consume 
specialist time. This assistant provides instant, grounded answers based 
on real implementation knowledge — reducing time-to-value for clients.

## Tech Stack
- Microsoft Copilot Studio
- Power Platform (dev tenant)
- Knowledge source: 8 Prism PPM implementation documents
- RAG-style grounded responses — no hallucinations

## Status
Portfolio proof-of-concept. Not a live client deployment.
